# Дизайн для недизайнеров — сайт курса

Онлайн-курс по основам дизайна для тех, кто делает презентации, посты, афиши и отчёты, но не учился на дизайнера. Восемь модулей: визуальная грамотность, Figma, композиция, цвет и типографика, UX, практика, ИИ в дизайне, итоговый проект.

Автор курса — Матвей Воронов, графический дизайнер ([портфолио](https://design.openline.one/)).

## Что на сайте

- **Главная** — первый экран, композиция из восьми фигур (по одной на модуль), программа из восьми плакатов, основа курса, принципы обучения, для кого курс и запись.
- **Страница модуля** (`#m01` … `#m08`) — темы, практическое задание, результаты, источники. Внизу переход к следующему модулю, после восьмого — к записи.
- Светлая и тёмная темы.

Стилистика и устройство повторяют сайт-портфолио автора ([Arelman/portfolio](https://github.com/Arelman/portfolio)).

## Как устроен репозиторий

Статический сайт без сборки и зависимостей: чистый HTML, CSS и JavaScript. Все пути относительные.

| Путь | Что внутри |
|---|---|
| `index.html` | разметка, стили и рендер страниц |
| `assets/course.js` | тексты: модули, принципы, аудитория, источники, контакты |
| `assets/art.js` | вся графика в SVG: обложки модулей, фигуры, учебные макеты «до / после» |

Посмотреть локально:

```bash
python3 -m http.server 4174
```

## Публикация

Каждый push в `main` выкладывает сайт через GitHub Actions (`.github/workflows/deploy.yml`) на сервер openline, как и портфолио. Нужны:

1. Переменная репозитория `CD_SERVER = https://deploy.openline.one` (уже задана).
2. Разрешение проекта на сервере (делает владелец сервера один раз):

```bash
sudo cdctl project add design-course --repo Arelman/design-course --type static --domain <домен>
```

## Источники

При разработке курса мы опирались на открытые учебные материалы MIT (курс 6.831: лекции по графическому дизайну, цвету и типографике), программу курса CalArts «Fundamentals of Graphic Design», исследования Nielsen Norman Group и книгу Робин Уильямс «Дизайн. Книга для недизайнеров». Программа построена по принципам обратного проектирования (Wiggins & McTighe) и First Principles of Instruction (M. D. Merrill).
